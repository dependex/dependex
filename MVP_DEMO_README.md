# OLTRE / DEPENDEX — MVP DEMO HOST

Questa build è una preview funzionante per visualizzare struttura, UX e core già integrato.

Include:
- Home OLTRE/DEPENDEX
- Login + recovery password senza email
- SQLite
- Dashboard user/admin base
- World Club Explorer 2D/3D
- Network Tree
- Registry e Club Card
- Academy base
- Eventi
- DAO base
- Lifestyle / missioni
- DRX base
- SIC-ID / Neuralog adapter già presenti nella build master

## Host requirements
- PHP 8.2+
- PDO_SQLite
- HTTPS consigliato
- cartelle data/ e storage/ scrivibili dal processo PHP

## Primo avvio
Aprire /install.php se il Super Admin non è già configurato.

Questa NON è la release finale production-ready. Alcuni moduli avanzati sono ancora in sviluppo/hardening.
