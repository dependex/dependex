# DRX e Rank

## Regola DRX
DRX = Dialogo · Relazioni · eXperienza. È l'unica unità reward.

## Daily
1 accesso reale/giorno = +1 DRX. Nessun recupero retroattivo degli accessi mancati.

## Sobrietà
1 giorno di sobrietà = +1 DRX.

## Rank User
- SEME: 0 DRX
- GERMOGLIO: 5000 DRX
- RADICI: 15000 DRX
- RAMO: 30000 DRX
- FIORE: 60000 DRX
- ALBERO: 120000 DRX
- BOSCO: 250000 DRX
- GUIDA: 500000 DRX
- MASTER: 1000000 DRX

## Rank eligibility
Quote/euro possono produrre DRX con `rank_eligible=false`; il Rank non si compra.
