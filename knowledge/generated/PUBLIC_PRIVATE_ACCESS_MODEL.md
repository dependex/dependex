# Public / Registered Access Model

## Public without registration
- Home / brand information
- Metodo DIPENDEX
- Privacy and Terms
- World Club Explorer 2D/3D
- Global Club Directory
- Public Club Cards
- Published events and event details
- Academy catalogue/information
- Public network information

## Registration/Login required
- User dashboard
- Personal profile and privacy settings
- Journal and check-ins
- DRX wallet, claims, missions, sobriety history
- Academy enrollments, progress, quizzes and certificates
- Event registration/check-in
- DAO/forum/voting
- Club Hub and internal topics
- Lifestyle personal history
- Assessments
- Finance, workflows, documents and administration
- Company Brain administrative consoles

## Registration
Self-service account creation creates:
- SIC-ID
- USER role
- password hash
- recovery-code hash
- privacy/terms consent records
- audit event
- trusted device
