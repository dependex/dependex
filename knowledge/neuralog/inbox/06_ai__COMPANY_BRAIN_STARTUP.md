# Company Brain Startup

## Concetto
Il Markdown è il DNA leggibile del progetto.
Neuralog trasforma i documenti in nodi e sinapsi.
Cortex usa il grafo e il RAG per operare sul sito.

## Pipeline
CODICE / DATABASE / RESEARCH / POLICY
→ Knowledge Builder
→ Markdown Archive
→ Neuralog Inbox
→ Chunking
→ Neuroni
→ Sinapsi
→ RAG
→ Cortex
→ Azioni assistite / workflow
→ nuovi eventi e conoscenza
→ aggiornamento Markdown / ingest

## Principi derivati dal pacchetto Company Brain
1. Impronta: identità, offerta/funzioni, utenti, tono, regole operative.
2. Mappa del Tesoro: mappare processi e micro-task.
3. Primo Ingranaggio: trasformare una priorità in skill operativa.
4. Knowledge viva: aggiornare i file quando il sistema cambia.
5. Data sovereignty: il cervello vive con i dati del progetto e può funzionare sul DB dell'app.

## Obiettivo OLTRE/DEPENDEX
Un Company Brain reale che conosce l'intero ecosistema e possa assistere amministrazione, community, ricerca, documenti, Academy, mappa, network, analytics e supporto operativo rispettando ACL e privacy.
