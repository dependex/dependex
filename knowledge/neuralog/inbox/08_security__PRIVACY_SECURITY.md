# Privacy & Security Knowledge

## Sensitive domains
Diario, chat, assessment, salute, famiglia, profili psicologici, recovery details.

## Regola
Privato per default. Scope e ruolo non equivalgono al diritto di leggere dati sensibili.

## AI
Shared intelligence solo aggregata/de-identificata.
API key, password, token, seed, private key e `.env` sono esclusi dall'ingest.

## Blockchain
Rimandata all'ultima fase. Nessun dato sanitario/personale on-chain.

## Recovery password
Trusted device + recovery code + fallback admin assistito con audit. Mai reset basato sulla sola conoscenza dell'email.
